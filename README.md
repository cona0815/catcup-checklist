# 貓咪盃備賽檢核系統

單檔網頁（index.html）＋ Google Apps Script 後端，給大橋國小參加全國中小學資訊應用競賽（貓咪盃）國小動畫 AI 互動組／國小遊戲 AI 互動組的學生使用。

- 前端版本：v1.0（2026-09-18）　檔頭與頁尾均標示
- 後端版本：Code.gs v1.0（2026-09-18）
- 資料檔版本：貓咪盃檢核資料 v1.2（2026-09-18，已內嵌於 index.html）

## 功能

| 分頁 | 內容 |
|---|---|
| 儀表板 | 總完成度（必做 50%＋技能精熟 35%＋文件 15%）、接下來做這三件事、分數在哪裡 |
| 必做功能 | 動畫 12 項／遊戲 14 項，每項寫明「做到什麼算完成」，可勾選、可加備註 |
| 技能樹 | 基礎／組別專屬／AI 共 26 項，三段狀態（還沒學／學過了／能自己做出來）、教學連結 |
| Scratch 基本功 | 在「技能樹 → 基礎」提供 9 課、19 個單元、15 個教學影片時間點與常用網頁；每個單元可獨立勾選完成並同步進度 |

「基礎」中與課程重疊的 4 項技能檢核直接放在對應課次後方，其他 6 項集中列出。原有技能 ID 與進度資料維持不變。
| 評分規準 | 116 官方配分、極優關鍵字、保底與拉高做法，交叉顯示對應檢核完成度 |
| 歷屆題目 | 114 全國、114 臺南、115 全國的考點拆解與必用模組 |
| 模擬出題 | **老師專用**（密碼 dcsp），依官方題型自動組題，儲存後學生端才看得到 |
| 說明文件 | 官方 116 範本欄位線上填寫、字數與關鍵字檢查、可複製／列印、附全球暖化填寫範例 |
| 賽程時間 | 210 分鐘八階段計時器、3 分鐘報告稿、最常踩的雷 |
| 設定 | 匯出／匯入進度、雲端重讀、老師工具（改密碼、全班進度、重置隊伍） |

## 部署步驟

### 一、後端（Google Apps Script）
1. 建立一份新的 Google 試算表 → 擴充功能 → Apps Script。
2. 把 `貓咪盃_GAS_Code_v1.0_20260918.gs` 全部內容貼進 `Code.gs`（取代原有內容）。
3. 執行 `setup()`，第一次會要求授權。完成後試算表會多出 `progress` / `links` / `mock` / `config` 四個分頁，教師密碼 `dcsp` 寫入指令碼屬性。
4. 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」→ 具有存取權的使用者「所有人」→ 部署。
5. 複製網頁應用程式網址（`https://script.google.com/macros/s/……/exec`）。
6. 在瀏覽器開 `該網址?action=ping`，看到 `{"ok":true,...}` 代表成功。

### 二、前端（GitHub Pages）
1. 建立一個 repo（例如 `catcup-checklist`），把 `index.html` 與 `basic-course.js` 放在根目錄。
2. 編輯 `index.html` 最上方的設定區，把剛才的網址填入：
   ```js
   const CONFIG = {
     GAS_URL: 'https://script.google.com/macros/s/XXXX/exec',
     TEACHER_PASSWORD_LOCAL: 'dcsp',
     ...
   };
   ```
   留空不填也可以運作，會變成「純本機模式」（只存在學生自己的瀏覽器）。
3. Settings → Pages → Source 選 `Deploy from a branch` → `main` / `(root)` → Save。
4. 約一分鐘後開啟 `https://<帳號>.github.io/catcup-checklist/`。

### 三、驗收
1. 開網頁 → 輸入隊名、姓名、選組別。
2. 勾一項必做功能 → 右下角出現「☁️ 已同步」→ 試算表 `progress` 分頁出現該列。
3. 右上角「老師登入」輸入 `dcsp` → 模擬出題頁出現「產生題目」→ 產生 → 儲存並發布 → 試算表 `mock` 分頁出現該列。
4. 用另一台裝置開同一網址、輸入同一隊名，應讀得到雲端進度。

## 修改內容

- 改檢核項目、技能、教學連結、評分規準、句庫 → 直接編輯 `index.html` 裡的 `const DATA = {...}`（即 `貓咪盃檢核資料_v1.2_20260918.json` 的內容），不需要動程式邏輯。
- 改 Scratch 基本功課程與常用網頁 → 編輯 `basic-course.js`。
- 改教師密碼 → 網頁「設定 → 老師工具 → 修改教師密碼」，或在 Apps Script 專案設定的指令碼屬性改 `TEACHER_PASSWORD`。
- 學生自己補教學連結不會存到雲端；老師模式加的連結會存入 `links` 分頁，所有人都看得到。

## 注意

- `index.html` 檔名固定（GitHub Pages 需求），版本號寫在檔頭註解、右上角標籤與頁尾。
- POST 一律用 `Content-Type: text/plain`，避免跨網域 preflight 被 GAS 擋掉，請勿改成 `application/json`。
- 學生端的勾選會同時存在瀏覽器 localStorage 與雲端；雲端不通時仍可正常使用，恢復後重新讀取即可。
